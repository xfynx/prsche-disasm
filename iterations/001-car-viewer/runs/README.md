# Viewer runs

Здесь хранятся воспроизводимые визуальные запуски viewer-а. Игровые ресурсы,
сборочные артефакты и `target` сюда не копируются.

## Именование

Каждый запуск получает отдельную папку:

```text
NNN-краткое-описание/
  README.md
  *.png
```

В README запуска фиксируются:

- дата и цель запуска;
- команда;
- автомобиль и параметры камеры;
- что проверялось;
- краткое наблюдение по результату.

Номер запуска увеличивается последовательно. Снимки из таких папок являются
частью исследовательской истории и могут версионироваться Git-ом.
