# 005-unified-driving

Статус: завершена и проверена; тег `iteration-005`. Пользователь подтвердил
работу интерактивного native-окна и desktop-лаунчера.
Самостоятельный снимок 004, собственные runs начинаются с 001. `local/game` read-only.

Цель: общая рабочая среда desktop/web и геометрическая основа восстановления
физики игры. Процедурную машину только исправляем; полный перенос включает обе
карьеры и остальные режимы — [дорожная карта](../../docs/roadmap.md).

## Запуск

Из корня репозитория:

```powershell
. .\scripts\tool-env.ps1
.\scripts\build.ps1 -Iteration 005-unified-driving -Config release -Target all
.\scripts\launch-viewer.ps1 -Mode desktop
# Или -Mode web / -Mode native
```

В `local/builds/005-unified-driving/` также создаются `Launch-desktop.cmd`,
`Launch-web.cmd`, `Launch-native.cmd`. Desktop — общий web/WASM UI в отдельном
окне Edge/Chrome, Python-сервер слушает только loopback. Консоль launcher должна
оставаться открытой; Ctrl+C останавливает его сервер, браузер закрывается отдельно.
Это переходная оболочка; окончательный native-порт не будет требовать браузер.

Native: `windows/porsche-viewer.exe` без аргументов открывает каталог;
`catalog --game-dir <path>` задаёт источник. Tab переключает авто/трассы,
PgUp/PgDn или [/] — ресурс. Прежние `inspect/view --game-dir ... --car/--track ...`
и offscreen `--screenshot` сохранены. Все платформы используют один Rust renderer.

Web/desktop: F — заезд, WASD/стрелки — газ/руль, Space — ручник, C — камера,
P — цвет, R — сброс, T — границы, Esc — меню, H — приборы. Диагностика открывается
отдельно. Выбор оригинальной модели пока относится к просмотру, не к машине заезда.

## Изменения и проверки

- Независимый от GPU spatial grid статических RD* треугольников CRP до batching.
  Запрос высоты/нормали выбирает ближайшую допустимую опору к текущей Y;
  сохраняет article/mesh/primitive/triangle identity. Выбор RD* — геометрическая
  гипотеза, а не доказанная семантика коллизий оригинального EXE.
- Руль и педаль сглажены, угол ограничивается скоростью. Максимум прототипа
  240 км/ч, шаги ≤1/120 с, кромки другого уровня не блокируют машину.
  Native обрабатывает удержание нескольких клавиш каждый кадр, не по автоповтору.
- 72 unit tests passed, 3 отдельных GPU tests ignored; fmt/clippy `-D warnings`
  чистые, release native/WASM собраны. 44/44 авто загружаются.
- 15/15 трасс прошли audit всех принятых треугольников, ошибка высоты до 0.000164 м.
  Узкий треугольник Monaco3 выявил потерю точности f32; запрос теперь считает
  barycentric coordinates в f64 с масштабируемым допуском границы.
- Playwright Chromium: заезд/газ+руль, скрытие HUD, меню, переключение skidpad/alps/356a,
  диагностика и отпускание ввода при потере фокуса — passed, page errors 0.
- Native offscreen Vulkan: skidpad и 356a осмотрены. Снимки и команды:
  [runs/001-unified-driving](runs/001-unified-driving/README.md).

## Ограничения и продолжение

Кромки всё ещё обрабатываются упрощённо, оригинальные flags не расшифрованы до
поведенческой семантики. Нет полноценного контакта с объектами, подвески, прыжков,
повреждений. При отсутствии дорожного треугольника прототип сохраняет предыдущую
высоту; это не модель свободного падения. Допуски опоры +2/-4 м — настройки прототипа.
Нормали доступны для будущей симуляции; нынешний наклон машины берётся из нескольких
запросов высоты. Кандидаты RD* могут включать геометрию, не являющуюся дорогой оригинала.

Обычный Chromium проверен с GPU. Headless-shell здесь не предоставил WebGPU adapter.
Интерактивный запуск native-окна и desktop-лаунчера проверен и подтверждён пользователем;
Linux/macOS не проверены.
