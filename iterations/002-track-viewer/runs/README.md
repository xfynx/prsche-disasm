# Viewer runs

Здесь хранятся воспроизводимые визуальные запуски viewer-а. Игровые ресурсы,
сборочные артефакты и `target` сюда не копируются.

## Именование

Каждый запуск получает отдельную папку:

```text
NNN-краткое-описание/
  README.md
  *.png
```

В README запуска фиксируются:

- дата и цель запуска;
- команда;
- автомобиль и параметры камеры;
- что проверялось;
- краткое наблюдение по результату.

Номер запуска увеличивается последовательно, начиная с `001` для текущей итерации
(например, `001-track-baseline`). Папки `runs` из предыдущих итераций не переносятся:
визуальная история предыдущих этапов остаётся в их собственных завершённых снимках
(`iterations/001-car-viewer/runs`). Папки со снимками хранятся только локально в рамках
актуальной итерации. Снимки из таких папок являются частью исследовательской истории
и могут версионироваться Git-ом.

## Журнал запусков

- [`001-track-baseline`](001-track-baseline/README.md): базовый рендеринг трека `skidpad`, обзор всей трассы, макро-план стыка блоков `RD0040C`/`RD0048C` и объектов окружения (отбойники, стена, деревья).
- [`002-texture-format-and-batching`](002-texture-format-and-batching/README.md): исправление декодирования 16-битных текстур FSH `0x7e` (ARGB 1555), батчинг мешей по материалам (-97% буферов), устранение артефактов фиолетовой пикселизации и детальная визуальная верификация с приближением (`farmland`, `castle`, `foothills`).
