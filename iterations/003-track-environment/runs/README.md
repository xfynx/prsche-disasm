# Viewer runs

Здесь хранятся воспроизводимые визуальные запуски viewer-а. Игровые ресурсы,
сборочные артефакты и `target` сюда не копируются.

## Именование

Каждый запуск получает отдельную папку:

```text
NNN-краткое-описание/
  README.md
  *.png
```

В README запуска фиксируются:

- дата и цель запуска;
- команда;
- автомобиль/трасса и параметры камеры;
- что проверялось;
- краткое наблюдение по результату.

Номер запуска увеличивается последовательно, начиная с `001` для текущей итерации.
Папки `runs` из предыдущих итераций не переносятся: визуальная история предыдущих этапов
остаётся в их собственных завершённых снимках (`iterations/002-track-viewer/runs`).

## Журнал запусков

- [`001-environment-baseline`](001-environment-baseline/README.md): базовое визуальное окружение трека `skidpad`:
  - Расстановка динамических объектов сценария (`.scn`): конусы `CONE`, стартовые стрелки `ARW1`.
  - Рендеринг купола неба `Sky/Skidpad.fsh` (`horz`): 360° цилиндрическая панорама горизонта с плавным затуханием в надир.
  - Общий вид трека, макро-вид конуса на асфальте, стартовая стрелка и вид с водительской позиции.
