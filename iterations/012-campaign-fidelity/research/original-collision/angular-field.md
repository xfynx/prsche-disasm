**Binding.** `car+0x38c` is the Y-axis component of the car's three-component angular velocity state, used to advance its orientation. It is a rate/state field, not the accumulated yaw angle. The direct binding is the original orientation update: `0x49b905`, `0x49b91c`, and `0x49b92c` read `car+0x388/+0x38c/+0x390`, respectively, multiply each by the same `0x5b2828 = 0.015625`, and pass them through X/Y/Z rotation-matrix constructors `0x5325a0`, `0x532600`, `0x532660`. The Y constructor writes a 3x3 rotation matrix with XZ sine/cosine terms and Y diagonal `1` (`0x532625..0x53264a`); `0x49b968..0x49b9a6` multiplies the three matrices into the orientation at `car+0x364`. The indexed multiply helper `0x532470` performs 3x3 products. This establishes the Y/yaw axis regardless of local coordinate naming.

**Units established by code.** The trigonometric wrappers `0x5327e0` and `0x5327f0` multiply their input by the double at `0x5bb2c0 = 6.28318452835083` before `fsin`/`fcos`. Thus the Y rotation per orientation update is `car[0x38c] * (1/64) * about 2π` radians, or `car[0x38c]/64` turns. Interpreting the field as turns/second requires independent proof that this update's `1/64` is seconds; the inspected code alone does not prove the wall-clock cadence. It is not directly radians/second or a yaw angle.

**Writers/readers.** The impact callback `0x493f10` writes `car+0x38c` at `0x493fd7/0x493fec`; `0x494000` invokes it at `0x494348` when its branch permits. The main state update `FUN_0049f160` reads `car+0xd38`, multiplies by `0x5b24b8 = 1/32` or `0x5b4a74 = 1/48` depending on `[car+0x558]+0x518`, adds to `car+0x38c`, and stores the result (`0x49fada..0x49faf8`). The same block updates linear vector `+0x33c/+0x340/+0x344` and angular vector `+0x388/+0x38c/+0x390` from neighboring triplets; the physical meaning of the `+0xd38` source and conditional timestep remains open. `FUN_0049bba0` limits each angular component using the same magnitude bound (`0x49bbe8..0x49bc74`). `FUN_00499a70` writes all three components from dot products against the car's basis (`0x49a716..0x49a750`), further showing a vector quantity.
