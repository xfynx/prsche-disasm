# Run 009 — общий индекс оригинала

2026-10-03. По запросу пользователя построен общий индекс до дальнейшей реализации.
Индекс и инструкции: [research/binary-index](../../../../research/binary-index/README.md).
Все текстовые данные версионируются и доступны обычному поиску по репозиторию.

Охват: 26 файлов EXE/DLL/ASI/OCX; 25 PE-путей, 24 уникальных PE-хеша, все имеют
Ghidra-экспорт. clcd16.dll — 16-битный NE, который этот анализ не покрывает.
Одинаковые voodoo2z.dll связаны как алиасы.

Итог без повторов: 36 510 функций, 169 794 связей вызова, 1 274 749 ссылок,
33 414 распознанных строк, 17 049 неразрешённых косвенных вызовов.
Полная сводка — research/binary-index/coverage.json. Наличие индекса не доказывает
полноту автоанализа или восстановление поведения. Для cached-export степень
завершённости анализа оставлена неизвестной; флаги сохранены отдельно.

Добавлены генераторы PE/Ghidra, сводка покрытия и поиск по строке/VA с callers,
callees и необязательным дизассемблированием. Поиск сверяет SHA256 оригинала.
Проверены _FStart.scn → Porsche.exe 0x46d600 и nfs5.exe 0x49c922 → функция
0x49c6c0; синтетический тест PE-экспортов/адресов прошёл.

Ghidra анализировал в отдельном проекте local/experiments/binary-index-ghidra.
Существующий исследовательский проект и lock не менялись. В первом экспорте
исправлена несовместимость Windows-пути /F:/...; затем экспорт повторён из базы
без повторного анализа. Скрытая ISSkin.dll включена в рекурсивный охват.
Подробные логи: local/reports/binary-index-*.log.

Правило «сначала индекс оригинала» закреплено в AGENTS.md и
.cursor/rules/original-index-first.mdc. README проекта и итерации обновлены.
Следующий шаг: по индексам восстановить нужные consumers миссии/физики,
затем завершить 0M01 в исходном лимите. Run 008 сохранён коммитом 9efb71c.
