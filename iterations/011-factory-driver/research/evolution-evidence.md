# Доказательная база режима Evolution: турниры, авторынок и запчасти NFS 5

Дата: 2026-09-24. Снимок: `010-evolution-career`.
Исследуемые компоненты: `local/game/FEData/Data/nfs5.prt`, `nfs5.trn`, `nfs5.car`, `nfs5.trk`, `festrings.csv`.

## 1. Турниры Evolution (`nfs5.trn`)

- Размер файла: 118 720 байт. 35 турнирных записей по 3 392 байта каждая.
- Каждая запись содержит:
  - Смещение `0x00`: Имя турнира (ASCII, 32 байта).
  - Смещение `0x20` (32): String ID имени в `festrings.csv` (напр. 2000 = «356 Challenge», 2005 = «914 Trophy»).
  - Смещение `0x24` (36): String ID описания турнира (напр. 2018).
  - Смещение `0x28` (40): Вступительный взнос (Entry Fee) в кредитах.
  - Смещение `0x2c` (44): Призовой фонд 1-го места (First Prize).
  - Смещение `0x30` (48): Допустимая эпоха и класс автомобилей.
  - Массив этапов (Stages): до 8 этапов, каждый содержит ID трассы, конфигурацию (Forward/Reverse), число кругов (от 2 до 5) и число соперников (до 7 ИИ).
- **Эпохи Evolution**:
  1. **Classic Era (1950–1969)**: Турниры 0..16 (356 Challenge, 550 Spyder Trophy, 911 Debut Cup, 912 Invitational, Classic Championship).
  2. **Golden Era (1970–1988)**: Турниры 17..27 (914 Trophy, 924/944 Challenge, 928 Grand Touring, 930 Turbo Cup, Golden Championship).
  3. **Modern Era (1989–2000)**: Турниры 28..34 (964 Carrera Cup, 993 GT2 Challenge, Boxster Trophy, 996 World Championship).
- **Система очков за этапы турнира**:
  - 1-е место: 10 очков
  - 2-е место: 6 очков
  - 3-е место: 4 очка
  - 4-е место: 3 очка
  - 5-е место: 2 очка
  - 6-е место: 1 очко

## 2. Каталог запчастей и тюнинга (`nfs5.prt`)

- Размер файла: 245 880 байт. Ровно **683 детали** по **360 байт** на запись (`245880 / 360 = 683`).
- **Формат 360-байтной записи детали**:
  - `0x00` (u32): Уникальный ID детали (1..683).
  - `0x04` (u32): String ID названия детали в `festrings.csv` (напр. «1500 S Engine Upgrade», «Sport Brake Package»).
  - `0x08` (32 байта ASCII): Код совместимой модели Porsche (напр. `356`, `356A`, `356B`, `550A`, `911`, `914`, `928`, `944`, `993`, `996`, `boxster`).
  - `0x28` (32 байта ASCII): Категория детали:
    - `Engine`, `Engine (Standard)`: двигатель и блок цилиндров.
    - `Carbs`, `Fuel Injector`, `Air Intake`: топливно-воздушная система.
    - `Exhaust`: выхлопная система.
    - `Flywheel`: облегчённый маховик.
    - `Gear Box`, `Shifter`: коробка передач и кулиса.
    - `Brakes`: тормозная система.
    - `Springs`, `Shocks`, `Sway Bars`: подвеска (пружины, амортизаторы, стабилизаторы).
    - `Rims`, `Tires`: колесные диски и шины.
    - `Body`, `Doors`, `Hood`, `Roof`, `Spoiler`: кузовные панели и аэродинамика.
  - `0x5c` (u32): Каталожная стоимость детали (Price) в кредитах CR.
  - `0x60` (f32): Базовый ресурс/износ (100.0 = новая деталь).
  - `0xc0` (f32): Основной коэффициент модификации:
    - Для тормозов (`Brakes`): множитель тормозного момента (1.0 -> 1.5 -> 2.0).
    - Для пружин (`Springs`): жесткость (1.0 -> 1.5 -> 2.0) и занижение клиренса на `0xc4` (0 -> 5мм -> 15мм).
    - Для амортизаторов (`Shocks`): коэффициент демпфирования (1.0 -> 1.8).
    - Для стабилизаторов (`Sway Bars`): сопротивление крену (1.0 -> 1.2).
    - Для КПП (`Gear Box`): главная пара на `0xc0`, передаточные числа задней `0xf0`, 1-й `0xf8`, 2-й `0xfc`, 3-й `0x100`, 4-й `0x104`, 5-й `0x108`.
    - Для двигателя (`Engine`): максимальные обороты (отсечка) на `0xc0` (5500..7000 RPM) и 21-точечная сетка крутящего момента в Нм со смещения `0x110` с шагом 500 RPM.

## 3. Авторынок (Dealership) и износ

- **Новые автомобили**: продаются без износа (состояние 100%), цена по каталогу `nfs5.car`.
- **Подержанные автомобили**:
  - Случайный исторический пробег (от 15 000 до 120 000 км).
  - Износ деталей (состояние от 30% до 85%).
  - Снижение цены: `рыночная_цена = базовая_цена * (0.35 + 0.65 * среднее_состояние_узлов) * фактор_пробега`.
- **Ремонт**: стоимость восстановления изношенной детали равна `цена_детали * (1.0 - текущее_состояние) * 0.8`.
- **Продажа авто игроком**: игрок получает остаточную рыночную стоимость своего авто с учётом установленных деталей и их износа.
