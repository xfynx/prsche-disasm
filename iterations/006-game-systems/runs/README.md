# Viewer runs

Здесь хранятся воспроизводимые визуальные запуски текущей итерации. Предыдущие запуски остаются в своих завершённых снимках.

Каждый запуск получает отдельную папку `NNN-краткое-описание/` с `README.md` и снимками.

## Запуски итерации

- [001-game-systems](001-game-systems/README.md) (2026-09-23): верификация симуляции, AI, карьер, профилей игроков и детерминированных реплеев. Полная сборка native + WASM, 83 теста пройдены.
