# Run 001: Верификация визуализации топологии и границ дорожного полотна

Дата: 2026-09-23

## Цель
Проверить корректность парсинга и рендеринга 3D границ дорожного полотна (`.edg`), соединений (`.jnc`) и карты секций (`.map`), а также подтвердить отсутствие регрессий при отображении автомобилей.

## Команды запуска
```bash
# 1. Трасса Skidpad с наложением границ дорожного полотна
porsche-viewer.exe view --game-dir local/game --track skidpad --screenshot skidpad_topology.png

# 2. Трасса Autobahn с границами
porsche-viewer.exe view --game-dir local/game --track autobahn --screenshot autobahn_topology.png

# 3. Регрессионный снимок автомобиля Porsche 356A
porsche-viewer.exe view --game-dir local/game --car 356a --screenshot car_356a_regression.png
```

## Результаты
- `skidpad_topology.png`:
  - 167 сегментов дорожных кромок, объединённых в 121 непрерывную линию (`TopologyLine`).
  - Линии границ корректно очерчивают круговое полотно и тестовые зоны с защитой от z-fighting (полигональный оффсет в шейдере `clip_pos.z - 0.0004 * clip_pos.w`).
- `autobahn_topology.png`:
  - Сложная многополосная сеть и съезды автобана корректно отрендерены поверх меша ландшафта.
- `car_356a_regression.png`:
  - Автомобиль загружается без искажений, геометрия и текстуры идентичны предыдущей итерации. 0 регрессий.

## Веб-версия
- Заменён `<input list="datalist">` на нативный выпадающий список `<select id="targetSelect">`, позволяющий выбирать трассу/авто в один клик без стирания текста.
- Добавлен чекбокс «3D Границы» и горячая клавиша `T` для мгновенного включения/отключения линий границ.
- При выборе трассы/авто в выпадающем списке происходит автоматическая смена сцены без необходимости нажимать кнопку загрузки.
