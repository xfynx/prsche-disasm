# Run 001: регресс управления после 008

Дата: 2026-09-24. Снимок: 009-game-shell. T00 пройден, итерация остаётся открытой.

Пользователь обнаружил перепутанные направления при движении вперёд в режиме F
в 008. В 6 DOF положительная команда «вправо» вращала колёса вокруг +Y на
положительный угол, что при направлении автомобиля -Z даёт левый поворот.
В 009 исправлен знак физических и визуальных колёс. 001–008 не изменены.

## Регресс

- `vehicle.rs`: реальное движение по синтетической плоской поверхности,
  лево/право, вперёд/назад, yaw 0/0.7, направление визуальных колёс.
  Исполнитель воспроизвёл падение теста до исправления и успех после.
- `arcade.rs`: направление траектории и носа для обеих скоростей и команд,
  четыре начальных направления. Знак аркадного руля менять не требовалось.
- `native.rs`: WASD/стрелки/ручник, комбинации кнопок, отпускание и сброс ввода.
- `web/ui.test.mjs`: реальные JS-обработчики клавиш и updateNavigation;
  газ+лево/право, задний ход, взаимная компенсация, ручник и потеря фокуса.
- `web/verify-browser.cjs`: клавиши → WASM → направление машины в обеих моделях;
  численная проверка знака относительно исходного правого вектора и снимки.
  Чтение телеметрии подключается самим тестом, без глобального test API в main.js.
- CI переключён на 009 и выполняет Rust workspace tests и web input regression.
