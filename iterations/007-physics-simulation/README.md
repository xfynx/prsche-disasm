# 007-physics-simulation

Статус: завершена и проверена (Run 001).  
Снимок создан из `006-game-systems` (скрипт `scripts/new-iteration.py`).  
Тег: `iteration-007`.  
Собственная история runs: `runs/001-physics-simulation/`. `local/game` read-only.  

Цель: восстановить аутентичную детерминированную симуляцию физики автомобиля и взаимодействия с дорожным полотном на основе доказанных параметров `.sim`, открытых в итерации 006.

## Основные направления

1. **Движок динамики твёрдого тела (6 DOF Rigid Body)**:
   - Изолированный от GPU модуль кинематики и динамики твёрдого тела (позиция, кватернион ориентации, линейная и угловая скорости).
   - Интегратор с фиксированным шагом (60 Гц с подшагами $\le 1/240$ с) для гарантированной детерминированности на всех платформах.
   - Физические параметры из `SimCar`: масса, координаты центра масс ($X, Y, Z$), моменты инерции.

2. **Силовая установка и трансмиссия**:
   - Двигатель: сплайн-интерполяция кривой крутящего момента по 21 точке доказанной 500-RPM сетки.
   - Модель оборотов: холостой ход (`idle_rpm`), инерция маховика, отсечка (`redline_rpm`).
   - Трансмиссия: передаточные числа $1..6$, задняя передача, нейтраль, главная передача (`final_drive`).
   - Крутящий момент на ведущих колёсах с учётом передаточных чисел и КПД привода.

3. **4-колёсная независимая подвеска и опора**:
   - 4 независимых колеса с геометрией базы (`wheelbase`) и колеи (`front_track`, `rear_track`).
   - Запросы высоты и нормали через spatial grid `RoadSurface` (`surface.rs`).
   - Силы пружин и амортизаторов (разделение сжатия `bump` и отбоя `rebound` из `.sim`).
   - Динамический load transfer (перераспределение веса при ускорении, торможении и кренах).

4. **Шинная модель и сцепление**:
   - Продольное проскальзывание (slip ratio) и боковой увод (slip angle).
   - Нелинейная кривая сцепления и эллипс трения с коэффициентами `front_grip`/`rear_grip` из `.sim`.
   - Тормозная система с балансом передней и задней осей (`front_brake`/`rear_brake`).

5. **Калибровка и верификация по baseline стенду**:
   - Сверка ускорения 0–100 км/ч, торможения 100–0 км/ч и боковых перегрузок с эталоном `local/experiments/bench/sim_baseline.json` для трёх контрастных авто:
     * *1956 356 A*: 60.0 hp, 0–100 за ~11.6 с, max 0.78g.
     * *1997 Boxster*: 181.2 hp, 0–100 за ~5.6 с, max 0.91g.
     * *1998 911 GT3*: 349.2 hp, 0–100 за ~4.0 с, max 1.02g.
   - Воспроизведение детерминированных потоков управления из `.rpl` (`ReplayFile`).

6. **Интеграция в Viewer**:
   - Анимация кузова и независимых колёс (вращение, поворот руля, ход подвески).
   - Телеметрический HUD (скорость, тахометр, передача, перегрузка $g$, контакт шин).
