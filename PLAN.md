# План восстановления Porsche Unleashed

## Цель и постоянная документация

Восстановить поведение оригинальной PC-игры и создать самостоятельный движок
на Rust + wgpu + winit для Windows, Linux, macOS и браузера (WebAssembly/WebGPU). Первая функциональная веха —
машина `356a` с оригинальными текстурами, вращением и приближением камеры.

Поддерживать README.md (навигация и запуск), PLAN.md (актуальный план),
STATUS.md (состояние и следующий шаг), docs/ (окружение, форматы, решения).
Документация на русском. При начале итерации записывать цель; после открытия,
изменения решения и проверок обновлять документы; перед завершением сеанса
актуализировать статус. Факты отделять от гипотез. Для бинарников сохранять
SHA-256, модуль и RVA; для внешнего кода — источник, коммит и условия использования.

## Git и итерации

Один локальный Git-репозиторий, main, без удалённого репозитория. Каждая большая
итерация — полный независимый снимок исходников, Cargo workspace, тестов,
конфигураций, lock-файлов и документации в iterations/NNN-name.
Следующая создаётся копированием предыдущей без сборок и кэшей. Межитерационные
зависимости запрещены. Завершённые снимки неизменны. Исправления — в следующей.
README снимка содержит цель, статус, состав, отличия, требования, команды,
результаты, ограничения и тег. При закрытии — снимок плана и документации,
коммит и аннотированный тег iteration-NNN. Не закрывать этап с невыполненными
критериями. Скрипт новой итерации запрещает перезапись существующей папки.

Игровые данные, инструменты, сохранения, базы Ghidra и кэши — вне Git в local/.
Роли агентов — в проекте. Исходный каталог игры только читается.
Все итерации и новый движок читают одну общую папку local/game. Нельзя копировать
ресурсы в снимки или браузерный пакет. Дополнительная копия допускается только
для эксперимента, который изменяет файлы (включая запуск оригинала).
Сильная доступная модель координирует; исполнители выбираются по сложности
из любых провайдеров. Принципы назначения: docs/agents.md, без привязки к брендам.

данным и оригиналу, не угадывать по имени. Непонятные обязательные поля
исследовать через Ghidra/x32dbg. Ошибка парсера указывает файл и смещение.
Выбрать неповреждённую комплектацию с максимальной доступной детализацией.

Уточнение 2026-09-17: довести эту итерацию до корректной базовой сборки всех
моделей из ресурсов `CarModel`, включая полицейские и низкодетальные модели.
Выбирать статьи по `Base`, доступным уровням и связанным `pr`, проверять весь
локальный набор и сохранять визуальные проверки в `runs`. Дополнительные хоткеи
не входят в этот этап.

Vulkan на Windows/Linux, Metal на macOS. Базовое освещение, текстуры, глубина,
прозрачность; вращение мышью, масштаб колесом, R — сброс; resize/minimize.
Преобразование координат — в слое ресурсов. Точные отражения и физика позже.

Дополнение пользователя: локальный сайт без публикации. Общие загрузчики и
рендерер собираются в WebAssembly; браузер выбирает игровые файлы локально,
без передачи на сервер. Один сценарий сборки создаёт Windows executable и
браузерный пакет. Отдельный локальный HTTP-сервер слушает только localhost,
обслуживает только сайт. WebGPU требует совместимый браузер; показывать понятную
ошибку при отсутствии API. Игровые данные не включать в сайт или git.

Готовность: самостоятельный просмотрщик отображает все 44 базовые модели CarModel
без известных дефектов, с проверенными текстурами и управляемой камерой.
Native/WASM сборки и графические smoke-тесты обязательны. Заглушки этап не закрывают.

Приёмка 001: браузер подтверждён пользователем, native — offscreen GPU;

## Проверки и продолжение

Тесты декомпрессора и парсеров: корректные/обрезанные данные, размеры, смещения,
индексы. Сверка распаковки со справочным декодером, геометрии и материалов —
с оригиналом. Проверить 356a с нескольких ракурсов и дополнительно 356b.
CI: Windows/Linux x86-64, macOS ARM64; синтетические ресурсы. Реальные файлы —
локально. Различать сборку и проверенный графический запуск. Доступ к другим
ОС пока не подтверждён. При закрытии сохранять команды и результаты проверок.

Дальнейшие вехи: трасса → измерения оригинала → физика без графики → гонка с AI
→ остальные режимы, звук, меню, сохранения. Каждый этап получает полный снимок
и уточнённые критерии. Побайтовое совпадение EXE не требуется. Численную
совместимость x86/ARM и допуски определять экспериментально.
