# Примеры профилей агентов

TOML-файлы здесь — существующие примеры для Codex/OpenAI, не обязательный стек.
Правила проекта в `AGENTS.md` и `docs/agents.md` применимы к любым провайдерам
и локальным моделям. Конкретные model ID/effort заменяются под выбранную среду.

При переносе сохранять обязанности ролей, границы файлов, проверки и экономию
контекста; формат конфигурации и параметры адаптировать к используемому клиенту.
Не считать одинаковые названия уровней рассуждения эквивалентными у разных моделей.
Не копировать эти профили автоматически в среду другого провайдера и не выдавать
примеры за уже настроенную интеграцию. Ключи доступа в репозитории не хранить.

Изменения этих примеров не обновляют автоматически локальные `.codex/agents`.
Настройка конкретного провайдера/клиента выполняется отдельно по запросу пользователя.
