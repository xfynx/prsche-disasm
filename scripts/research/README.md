# Исследовательские скрипты реверс-инжиниринга

Утилиты и зонды для анализа оригинальных форматов и бинарников NFS: Porsche Unleashed (2000).

## Сначала общий индекс

Перед реализацией поведения используем [Run 009](../../iterations/012-campaign-fidelity/runs/009-binary-index/README.md).

- `index-binaries.py`: рекурсивный PE-инвентарь, хеши, строки, импорты/экспорты,
  предварительные кандидаты функций/вызовов; не заменяет анализ границ функций.
- `index-ghidra.ps1`: пакетный анализ в отдельном Ghidra-проекте и экспорт функций,
  ссылок, строк, символов и неразрешённых косвенных вызовов.
- `query-binary-index.py`: поиск по строке или адресу с функциями и ссылками;
  проверяет хеш текущего бинарника перед использованием индекса.

Подробные результаты версионируются: `research/binary-index/`; оригиналы только читаются.

## Скрипты анализа форматов трасс

- **`disasm_loaders.py`**: дизассемблирование через Capstone функций загрузчиков `.edg` (VA `0x488090`) и `.jnc` (VA `0x487880`) в `nfs5.exe`.
- **`probe_edges.py`**: чтение и валидация 28-байтных структур границ дорог `.edg` (`flags`, `x1, y1, z1`, `x2, y2, z2`).
- **`probe_topology.py`**: анализ перекрёстков `.jnc` и контрольных сумм топологии трассы.

## Скрипты анализа моделей машин

- **`inspect_crp.py`**: парсер и инспектор бинарных секций CRP-архивов машин, пар иерархии деталей и полигональных сеток.
- **`probe_parts.py`**: анализ атрибутов кузовных панелей, флагов стилей и вариантов окраски.
- **`paint_probe.py`**: извлечение заводских цветовых палитр из ресурсов игры.

## Требования

- Python 3.10+
- `pip install capstone` (для `disasm_loaders.py`)
- Оригинальные файлы игры в `local/game/`
