# Принятые решения

- Новый движок: Rust, wgpu, winit. Поведение восстанавливаем; binary matching не цель.
- Первая визуальная веха — 356a, без временной физики.
- Полные независимые снимки исходников по итерациям, один Git-репозиторий.
- Общие игровые данные и инструменты — local/, вне Git.
- Эталонная копия игры неизменна; все запуски на экспериментальных копиях.
- Завершение этапа определяется проверками, а не объёмом написанного кода.
- GPT-6 координирует и решает сложные вопросы; реализация — GPT-5.6 Terra/GPT-5.5,
  ограниченные задачи скриптов — GPT-5.6 Luna. Назначения: agents.md.
- Дополнение: первая веха включает WebAssembly/WebGPU и локальный сайт, без
  хостинга. Одна команда собирает Windows и браузер. Ресурсы пользователь
  выбирает на диске, они остаются в браузере; HTTP-сервер не раздаёт папку игры.
