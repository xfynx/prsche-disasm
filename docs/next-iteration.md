## Цели и задачи 009-game-shell

1. **Главная игровая оболочка и конечный автомат экранов (Game Shell & Screen State Machine)**:
   - Общая кроссплатформенная модель экранов: Главное меню $\leftrightarrow$ Профиль игрока $\leftrightarrow$ Выбор режима (Одиночный заезд, Эволюция, Заводской водитель) $\leftrightarrow$ Гараж/Авто $\leftrightarrow$ Загрузка $\leftrightarrow$ Заезд (`008-race-loop`) $\leftrightarrow$ Результаты.
   - Поддержка навигации с клавиатуры, геймпада и мыши на Native и Web.

2. **Профиль игрока и сохранение/загрузка прогресса (Profile & Savegame System)**:
   - Структура профиля игрока: имя, баланс кредитов/денег, купленные автомобили и состояние пробега/износа, открытые эпохи и этапы Evolution, выполненные миссии Factory Driver.
   - Атомарное сохранение и восстановление при сбое (`atomic write` с fallback).
   - Поддержка сохранения в `savedata/` для Native и IndexedDB / localStorage с экспортом/импортом файла сохранения для Web.
   - Совместимость с парсером оригинального формата `.sav` из итерации 006.

3. **Движок событий и карьерных правил (Event Engine)**:
   - Загрузка структуры событий и условий из каталогов `nfs5.fac` (миссии Factory Driver) и `nfs5.trk` / `nfs5.car`.
   - Проверка условий допуска: класс автомобиля, год выпуска, эпоха, взнос за участие.
   - Связывание условий события с параметрами сессии `RaceSession` (трасса, класс ИИ соперников, количество кругов, целевое время, контрольные конусы/слалом).

4. **Первые сквозные сценарии обеих карьер**:
   - **Factory Driver (Задание 1)**: слаломная проверка маневрирования на тестовом полигоне / Skidpad с контролем времени и сбитых конусов $\to$ оценка результата $\to$ переход к Заданию 2 $\to$ сохранение прогресса.
   - **Evolution (Эпоха Classic, турнир 1)**: покупка первого доступного Porsche (например, 356 1100 или 356A) $\to$ участие в турнире из 3 заездов $\to$ начисление призовых $\to$ ремонт/сохранение состояния машины в гараже $\to$ сохранение профиля.

5. **Звуковое сопровождение (Audio Subsystem)**:
   - Базовая аудиосистема для Native (`rodio` / `cpal`) и Web (Web Audio API).
   - Модуляция высоты и громкости звука двигателя по RPM из `Powertrain`.
   - Звуки визга шин при пробуксовке/заносе, звук контакта с отбойником.

## Критерии готовности 009-game-shell

1. Полноценное главное меню и навигация между экранами без выхода в системную консоль.
2. Создание профиля игрока, сохранение на диск/в браузер, закрытие приложения, повторный запуск и продолжение карьеры.
3. Успешное сквозное прохождение первого задания Factory Driver и первого этапа Evolution с начислением наград и записью прогресса.
4. Нулевая регрессия: 100% тестов проходят, `cargo fmt --check`, `cargo clippy -- -D warnings`, успешные сборки release native и WASM.
