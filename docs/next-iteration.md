# 002-track-viewer — следующий этап

Статус 2026-09-19: запланирован, реализация не начата. Основа — принятый
снимок `iteration-001`; ресурсы только из общего read-only `local/game`.

## Цель

Загрузить и показать один реальный участок трассы с исходной геометрией,
размещением и текстурами в native/WASM. Сначала установить фактические форматы
и связи ресурсов; не подменять неизвестные данные заглушками.

## Порядок работы

1. Инвентаризировать каталоги/файлы трасс: имена, размеры, сигнатуры, связи.
   Выбрать минимальный репрезентативный участок, записать входные файлы и SHA-256.
2. Создать полный снимок 002 из 001, обновить его README/PLAN и ссылки сборки.
   001 не менять; старые runs сохранить как историю исходного снимка.
3. Formats: узкая задача — парсинг выбранного формата, проверки границ/индексов,
   преобразование в Scene. Подтверждённые факты и гипотезы разделять.
4. Renderer: только необходимая камера/загрузка сцены; сохранить car-viewer и
   корректное отображение материалов. Builds: native/WASM и повторяемый capture.
5. Координатор: визуальная проверка участка с нескольких ракурсов, сверка
   взаимного размещения блоков, итоговый протокол. Агентов назначать при старте,
   компактно, с непересекающимися файлами владения.

## Готовность

- Реальный участок, без выдуманной геометрии; видимые стыки/текстуры проверены.
- Ошибки ресурсов диагностируются с именем и смещением, без падений/выхода за границы.
- Парсерные тесты, native/WASM сборки, GPU-снимки и браузерная проверка.
- Автомобильная загрузка и тесты 001 не регрессируют.
- README/PLAN/STATUS актуальны, run содержит точные команды и наблюдения.

Не входит: физика, AI, гонка, полные CLR-палитры, все варианты повреждений/анимаций.
Native UI smoke из ограничений 001 проверить при доступном desktop connector.

Ближайшее действие: инвентаризация игровых трасс, затем:

```powershell
py -3 scripts/new-iteration.py --from 001-car-viewer --name 002-track-viewer
```

Не запускать повторно при существующей 002. После копирования сразу заменить
унаследованный PLAN: он описывает завершённую 001, а не активную работу 002.
