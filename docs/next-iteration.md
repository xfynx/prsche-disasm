# Текущий этап: v2/001-original-recovery

Решение пользователя 2026-10-08 заменяет прежний порядок: сохранить v1 как есть,
создать отдельную v2 и восстанавливать полный собираемый оригинал из бинарников.
Активный план — [v2/001](../iterations/v2/001-original-recovery/PLAN.md).
Уточнение: сразу C/C++; первый игровой запуск может быть позже. Run 002
создал адресное дерево и x86 библиотеку/probe. Run 003 восстановил девять
функций FE stream и сверил их на 236 случаях с оригинальным x86. Run 004
восстановил 11 функций собственного heap: 551 сравнение всей арены после
каждой операции прошли; всего 21 функция. Следующий пакет — файловые службы
FE: группы handles, completion/status, disk/archive backend; затем совместная
сверка FE/heap/IO и подключение к startup 0x4b6a50. Неизвестные OS/CRT/SIMD и
прочие callees остаются внешними зависимостями; записи есть только в стенде.
Сборки — `local/builds/v2/001-original-recovery`; данные `local/game` общие,
неизменяемые. 012 не объявляется завершённой. Прежний план ниже исторический,
включая перенос повреждений/б/у в 013: в v2 эти системы восстанавливаются
в полном исходном графе, новые номера этапов будут определены планом v2.

Обновление 2026-10-04: сначала завершаем 012 по оригинальному поведению,
без подбора похожей модели с нуля; существующую логику проверяем так же.
После — [план 013: повреждения и рынок б/у](planned-damage-used-cars.md).
Реверс контактов/damage начинается в 012; сама 013 ещё не создаётся.

Обновлено 2026-09-25. После замечаний пользователя к 011 приоритет изменён:
соответствие карьер оригиналу, старт миссий и устойчивость движения. 001–011 заморожены.
Снимок 012 создан из 011 без прежних runs. Код 011 сохранён как исторический результат,
но её прежние утверждения о полном соответствии не подтверждены текущей проверкой.

1. T01: экраны Evolution/Factory Driver: отдельные комнаты и правильные переходы,
   источники изображений/брифингов по Layouts оригинала. Никакого общего брифинга
   Рольфа со схемой 0M01 для Evolution. Эталонные кадры и сценарии, не только CSS.
2. T02: Factory Driver 0M01: старт/направление/сценарий/цели. Проверить SCN Start,
   отличать центр триггера от подтверждённой позиции автомобиля. Исправить общую
   стартовую решётку в миссиях; повтор должен возвращать к тому же старту.
3. T03: устранить импульс подвески при первом/повторном контакте, вымышленное
   полотно на y=0 при промахе и выбор другого уровня дороги. S тормозит до остановки,
   затем включает задний ход при удержании; W симметрично останавливает задний ход.
4. T04: реальные native/WASM сборки, браузерные проверки двух карьер, физические
   регрессы и источник каждого утверждения. Не объявлять весь Factory Driver
   восстановленным по наличию списка миссий или синтетическому тесту.
