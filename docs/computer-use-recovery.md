# Computer Use: передача после перезапуска, 2026-09-25

Native Computer Use ещё не проверен в новом процессе. До перезапуска продолжаем
работу с кодом, ресурсами и автоматическими проверками. Визуальное совпадение
оригинала и порта не считается подтверждённым.

Предыдущий `@oai/sky.list_apps()` возвращал `Computer Use native pipe is unavailable`
и Windows `os error 2`. В пользовательском `~/.codex/config.toml` были удалены только
два устаревших переопределения `SKY_CUA_NATIVE_PIPE` и `SKY_CUA_NATIVE_PIPE_DIRECTORY`.
Резервная копия: `~/.codex/config.toml.backup-computer-use-20260925-034039`.
TOML после правки проверен. Уже запущенный MCP сохраняет прежние переменные;
сброс JavaScript не обновил окружение процесса.

После переподключения Computer Use/перезапуска сеанса:

1. Прочитать актуальные инструкции доступного Computer Use и проверить список приложений.
2. Если доступен оригинал, работать с копией в `local/experiments/runtime`; `local/game`
   остаётся только для чтения.
3. Записать исходные экраны Evolution, Factory Driver, briefing/map и старт 0M01.
   Проверить реальные условия завершения, расположение машины и переходы.
4. Сопоставить с активной 012. Сохранять свидетельства в её `runs`, не в старых снимках.

Ручной запуск внутренних helper-процессов или завершение Codex для принудительного
перезапуска не выполнялись. Исправление конфигурации не означает, что native-доступ
уже восстановлен.
